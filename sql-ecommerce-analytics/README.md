# 📊 SQL Analytics Engine — E-Commerce Deep Dive

## 🚀 Overview
An advanced SQL analytics project using the Olist Brazilian E-Commerce dataset.

This project answers real business questions using:
- CTEs
- Window Functions
- Aggregations
- Cohort Analysis
- RFM Segmentation

## 🧠 Key Analyses

### 1. Customer Segmentation (RFM)
Identifies high-value customers based on recency, frequency, and monetary value.

### 2. Cohort Retention
Tracks how customers return over time.

### 3. Revenue Trends
Analyzes daily revenue, rolling averages, and YoY growth.

## 🛠 Tech Stack
- PostgreSQL
- Advanced SQL
- dbt (data modeling)
